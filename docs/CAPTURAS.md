# Evidencias visuales para README y rúbrica

Las imágenes 01 y 02 son representaciones visuales de las respuestas **reales HTML/CSS** que generó PHP en el servidor local (renderizadas en un navegador sin conectar con MySQL). No son capturas del despliegue público ni de una sesión autenticada. No prueban el CRUD ni el hosting. Antes de publicar en GitHub se deben añadir capturas reales de los estados autenticados:

- `03_dashboard_filtros.png`: panel con búsqueda por nombre/correo/ciudad y opciones de ordenamiento; puede contener contactos de prueba.
- `04_contacto_formulario.png`: formulario con selector de las cinco categorías y casilla Favorito.
- `05_favoritos.png`: filtro «Solo favoritos» mostrando contactos de prueba.
- `06_url_https.png`: navegador con URL real HTTPS del hosting y panel funcional, ocultando datos sensibles.

Para crearlas, usa `Windows + Shift + S`, selecciona la región, guarda con el nombre indicado y ubica los archivos en `docs/capturas/`. No presentes las capturas 01/02 como prueba de despliegue público. Evita datos reales, correos personales, cookies y contraseñas visibles.
